# Windows SOC Lab

A hands-on Windows Security Operations Center (SOC) lab focused on
security monitoring, Sysmon telemetry, process investigation,
and incident triage.

## Objective

This project documents practical SOC investigations performed in a
controlled Windows environment.

The goal is to develop practical skills in:

- Windows security monitoring
- Sysmon
- PowerShell
- Process analysis
- Command-line investigation
- Windows service investigation
- Event analysis
- Digital signature verification
- Alert triage
- Incident documentation

## Environment

| Component | Details |
|---|---|
| Operating System | Windows |
| Monitoring | Microsoft Sysmon |
| Investigation | Windows Event Logs |
| Scripting | PowerShell |
| Version Control | Git / GitHub |
